# Canteen Food Ordering App - Wireframes

## 📌 Project Overview
This repository contains the wireframes and user research for a mobile app designed to streamline food ordering in college canteens.

## 📂 Files Included
1. **Jaymendrasinh_Foodapp_Wireframe (1).zip** - Low-fidelity and high-fidelity wireframes for all screens
2. **Canteen Food Ordering App - Design Document.pdf** - User research with 10 interviews, personas, and insights

## 🎯 Key Features Designed
- Browse canteen menu with real-time availability
- Add to cart and customize orders  
- Multiple payment options
- Order tracking and history
- Rating & review system

## 🛠️ Tools Used
Figma for wireframing, Google Docs for user research
